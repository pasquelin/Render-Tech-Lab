# Hypothèse

Une hiérarchie spatiale conservative peut réduire le nombre de tests d'obstacles nécessaires aux ombres et aux reflets sans changer leurs intersections. Cette hypothèse porte sur le coût du rendu de la fixture ; elle ne promet ni fréquence d'affichage ni gain sur une scène générale.

La variante est rejetée si elle modifie l'image de référence au-delà du contrôle exact imposé par le protocole. Les coûts CPU du transport, CPU de soumission, GPU et les intervalles d'affichage permettent d'identifier le poste réellement modifié.

Un worker ou un autre format d'exécution CPU constituerait une expérience distincte. Le présent banc n'en déduit aucun résultat.
